# References

This file lists the sources behind the facts in this course: the Intel manuals for the CPU, the
BIOS interfaces the boot loader calls (INT 10h, 13h and 15h, E820), the PC's devices (the 16550
UART, the 8259 PIC, the 8254 PIT, the 8042 keyboard controller, VGA text mode), QEMU and SeaBIOS,
the GNU toolchain (NASM, gcc, ld, gdb), and the history the chapters tell: the IBM PC, the 286,
Linux 0.01, xv6 and others. Use it to check a claim or to read further.

Each source has two links: **original** (the live page) and **archived** (a snapshot in the
Internet Archive's [Wayback Machine](https://web.archive.org/), in case the original moves or
changes). For source code on GitHub, the archived link points to
[Software Heritage](https://archive.softwareheritage.org/), an archive of public source code;
where a release tag is pinned (SeaBIOS 1.15.0, Linux 2.6.12), the archived link names it too.
A book without a stable online copy is listed by title only.
Program output, sizes and timings shown in the chapters come from running the course's own code
on QEMU 6.2 and aren't listed here.
